# Outils utilisés pendant la formation

| Outil | Usage | Documentation |
|---|---|---|
| FastQC | Contrôle qualité des reads | https://www.bioinformatics.babraham.ac.uk/projects/fastqc/ |
| Fastp | Trimming et filtrage qualité | https://github.com/OpenGene/fastp |
| Bowtie2 | Alignement de reads courts | https://bowtie-bio.sourceforge.net/bowtie2/ |
| Minimap2 | Alignement rapide de reads courts/longs | https://github.com/lh3/minimap2 |
| metaSPAdes | Assemblage de novo métagénomique | https://cab.spbu.ru/software/meta-spades/ |
| AMRFinderPlus | Annotation des gènes de résistance | https://github.com/ncbi/amr |
| Kraken2 | Classification taxonomique par k-mers | https://ccb.jhu.edu/software/kraken2/ |
| Bracken | Ré-estimation d'abondance taxonomique | https://ccb.jhu.edu/software/bracken/ |
| Krona | Visualisation taxonomique interactive | https://github.com/marbl/Krona |
| Snakemake | Orchestration de pipelines reproductibles | https://snakemake.readthedocs.io/ |
| samtools | Manipulation de fichiers BAM/SAM | https://www.htslib.org/ |
| seqkit | Statistiques et manipulation de séquences FASTA/FASTQ | https://bioinf.shenwei.me/seqkit/ |
| DHIS2 | Système national d'information sanitaire | https://dhis2.org/ |

*Consulter chaque outil via le lien de documentation officielle pour les options avancées non couvertes en formation.*
