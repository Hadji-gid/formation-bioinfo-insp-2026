# Glossaire bio-informatique — Formation INSP 2026

| Terme | Définition |
|---|---|
| **ARG** | Antimicrobial Resistance Gene — gène conférant une résistance à un ou plusieurs antimicrobiens |
| **Assemblage de novo** | Reconstruction de séquences génomiques à partir de reads, sans génome de référence |
| **BAM/SAM** | Formats de fichiers standards stockant des reads alignés sur un génome de référence |
| **Contig** | Séquence continue résultant de l'assemblage de reads chevauchants |
| **FASTQ** | Format de fichier standard pour stocker des reads de séquençage et leurs scores de qualité |
| **IDSR** | Integrated Disease Surveillance and Response — système intégré de surveillance et de riposte aux maladies |
| **k-mer** | Sous-séquence de longueur k utilisée pour la comparaison rapide de séquences (ex. Kraken2) |
| **N50** | Indicateur de qualité d'assemblage : longueur de contig au-dessus de laquelle 50 % de l'assemblage est représenté |
| **NGS** | Next-Generation Sequencing — séquençage à haut débit |
| **Phred (score de qualité)** | Mesure logarithmique de la probabilité d'erreur d'appel de base (Q30 = 1 erreur pour 1000 bases) |
| **Pipeline** | Enchaînement automatisé d'étapes d'analyse bio-informatique |
| **Read** | Séquence individuelle produite par un séquenceur |
| **Reproductibilité** | Capacité à obtenir les mêmes résultats en ré-exécutant la même analyse sur les mêmes données |
| **Surveillance génomique** | Utilisation du séquençage pour suivre l'évolution et la propagation de pathogènes |
| **Trimming** | Suppression des portions de mauvaise qualité ou des adaptateurs résiduels d'un read |
| **Variant** | Différence de séquence par rapport à un génome de référence |
