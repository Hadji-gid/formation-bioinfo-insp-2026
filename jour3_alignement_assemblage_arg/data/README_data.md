# Données de l'exercice — Jour 3

## `reference_genome_exemple.fasta`
Séquence factice de 2000 pb générée aléatoirement, utilisée uniquement pour illustrer la mécanique des commandes d'indexation et d'alignement (Bowtie2/Minimap2). Ne correspond à aucun organisme réel.

## `arg_profile_exemple.tsv`
Exemple de sortie **au format réel d'AMRFinderPlus** (colonnes identiques à l'outil), avec des valeurs de gènes de résistance illustratives (blaCTX-M-15, tetA, sul1, aac(6')-Ib-cr, mcr-1.1) — couramment rencontrés en surveillance AMR en Afrique de l'Ouest. Les identifiants de contigs et coordonnées sont fictifs. Ce fichier sert de support de lecture avant de manipuler les vraies sorties générées sur les échantillons anonymisés du serveur INSP.
